# MSU MPI Workshop

A 3D wave-equation solver developed for an MSU parallel-programming workshop. MPI divides
the domain between processes, while OpenMP parallelizes computation within each process.

Решатель трёхмерного волнового уравнения, созданный для практикума МГУ по параллельному
программированию. MPI распределяет расчётную область между процессами, а OpenMP
распараллеливает вычисления внутри каждого процесса.

## Описание

Программа численно решает трёхмерное волновое уравнение с распределением расчётной
области между MPI-процессами и параллельными вычислениями OpenMP внутри процесса.
Соседние процессы обмениваются граничными слоями через неблокирующие операции MPI.

Запись снимков VTK зависит от макроса компиляции `data_write`, а вывод численной ошибки - от `error_write`. Суммарное время выполнения печатается независимо от этих макросов. Проект служит компактным примером гибридного численного кода на MPI + OpenMP.

## Разработка и проверка изменений

**Основные точки изменения:**

- `src/mpi.c` - распределение области между MPI-процессами, обмен граничными данными и OpenMP-вычисления;
- `CMakeLists.txt` - параметры сборки MPI и OpenMP.

**Модель и граничные условия:** в `src/mpi.c` функции `phi0` и `phi0t`
задают начальное поле и его скорость, а `source` - правую часть уравнения.
За значения на шести гранях отвечают `phi_x_0`, `phi_x_1`, `phi_y_0`,
`phi_y_1`, `phi_z_0` и `phi_z_1`; сейчас они возвращают ноль. Функция
`phi` задаёт аналитическое решение, с которым можно сопоставлять расчёт.
При изменении условий согласуйте инициализацию и обновление граничных
ячеек с обменом между MPI-блоками.

**Декомпозиция и обмен:** `main()` принимает число MPI-процессов только как степень двойки, распределяет множители по осям `x`, `y`, `z` и вычисляет локальные размеры через целочисленное деление `(N_x + 1) / num_blocks_x` (аналогично для других осей), добавляя по две halo-ячейки. Остаток деления не обрабатывается. Соседние ранги циклически замыкаются функцией `from_cord_rank()`, а обмен по шести граням использует пары `MPI_Irecv`/`MPI_Isend` и 12 запросов. При правках проверяйте размер сетки, делимость по всем осям, теги отправки и приёма и два временных слоя.

**Файлы сборки:** `CMakePresets.json` содержит профили конфигурации; `CMakeLists.txt` отвечает за подключение MPI и OpenMP. Условия вывода VTK и ошибки регулируются отдельно макросами в исходнике.

**Проверка изменений:** Проверяйте сборку и запуск из соответствующих разделов, включая несколько MPI-процессов. При изменении декомпозиции убедитесь, что обмены граничными слоями соответствуют локальным размерам сетки.

## Сборка

Нужны CMake, реализация MPI и поддержка OpenMP.

```sh
cmake --preset release
cmake --build --preset release
```

Исполняемый файл:

```text
build/release/mpi-waves
```

## Запуск

Количество MPI-процессов должно быть степенью двойки. Первый необязательный аргумент задаёт размер сетки по всем трем пространственным направлениям.

```sh
mkdir -p plot
mpirun -np 4 ./build/release/mpi-waves 127
```

Без аргумента используется размер сетки, заданный в исходном коде.

Программа всегда выводит параметры расчета и суммарное время работы. Значения L2 error печатаются только с макросом компиляции `error_write`, а VTK-файлы записываются в `plot/` только с `data_write`. Стандартный пресет `release` не задаёт эти макросы.

## Реализация

MPI используется для разбиения трехмерной области и обмена граничными слоями между соседними блоками. OpenMP распараллеливает вычислительные циклы внутри каждого MPI-процесса.

Это учебный/экспериментальный solver: параметры численной схемы и формат вывода намеренно находятся непосредственно в коде, чтобы реализацию было проще изучать и менять.
